# 多源遥感工具规划文献目录

这是写作 agent 的检索入口，不是给人速读的综述。目标是用尽量少的上下文完成三件事：定位相关论文卡片、读取已核对的结论、判断是否需要打开全文。

## 何时加载

在以下任一情况加载本目录：

- 撰写或修改开题报告、学位论文的引言、相关工作、方法、实验设计或讨论；
- 需要引用一篇遥感 / 地球观测 / 多模态 / agentic 论文，或核对它的会址、预印本状态、bib key；
- 需要核对某篇论文的结论、数字、评测协议、工具设置或原文表述；
- 需要判断某篇工作到底算 P1 工具规划、P2 轨迹后训练、感知底座，还是背景；
- 需要检查“这句话能不能写进正文”“这个分数能不能比较”。

配套材料：仓库根目录的 `papers.json`、`SURVEY.md`、`missing-pdfs.md`、`pdfs/`；开题参考文献 `ref.bib`（不在本仓库时，以卡片里的 bib key 状态为准）。

## 不要用它做什么

- 不要重写开题报告或论文正文；本目录只提供证据与路由。
- 不要把目录里的“关系标签”写进论文正文自我声明。
- 不要用本目录替代对 PDF 的核对，尤其是具体数字、表格、评测协议与原文引语。
- 不要把不同评测协议下的分数排成对照表或 SOTA 榜。
- 不要下载或打包付费墙正式版；缺全文就按缺全文处理。

## 强制阅读顺序

严格按以下顺序，不要一上来读 PDF：

1. 读 [`SKILL.md`](SKILL.md)（本页）与 [`CLAIM.md`](CLAIM.md)、[`INDEX.md`](INDEX.md)。
2. 只打开 **1–2 个** 相关 [`clusters/*.md`](clusters/) 主题簇。
3. 再打开 **1–3 张** 对应的 [`papers/<id>.md`](papers/) 卡片。
4. **仅当** 需要具体数字、评测协议、工具列表、表格/页码或原文表述时，才打开 `pdfs/` 中的全文。
5. 若 PDF 缺失（ExpertsRS、SPEXT），只能按卡片中的“缺失说明 + 正式页链接”引用，不得假装已读全文。

阅读预算：一次检索通常 = 1 个 cluster + 2–3 张卡；只有写方法对比或实验设计时才扩展到 2 个 cluster。

## 检索流程

1. **抽取查询**：从当前段落抽出 1–3 个要素：主张（P1/P2）、问题（灾害/SAR/工具选择/步骤–答案不一致）、方法（MCP/多 agent/蒸馏/RL）、基准（Earth-Bench/ThinkGeo/DORA/EO-Gym/VRSBench…）。
2. **先读 [`CLAIM.md`](CLAIM.md)**：确认这句话属于主张的哪一段，避免把背景写成贡献、把感知写成规划。
3. **在 [`INDEX.md`](INDEX.md) 选路径**：主张路径 / 问题路径 / 方法路径 / 基准路径；拿到 1–3 个候选 id。
4. **读对应 cluster**：只读“这类工作回答什么问题”“代表论文”“共同能力边界”“何时进入”。
5. **读论文卡片**：优先看“核心结论”“关键数字”“能力边界”“与主张的关系”“何时必须打开全文”。
6. **按需开 PDF**：只在卡片明确提示需要时打开；打开后只定位所需页/表/节，不整篇灌入上下文。
7. **组织回答**：按下面的固定格式返回；缺证据就写“还缺什么”，不要补全。

### 一个最小示例

查询：“论证光学–SAR 切换是 P1 的关键，而不是再训一个更强的灾害 VLM。”

1. `CLAIM.md` → P1a（切换决策应显式建模并可检验）。
2. `INDEX.md` → 问题路径“光学被云/烟/夜切断，需要 SAR 补盲” → `disaster-emergency` / `perception-foundation`。
3. 打开 `clusters/disaster-emergency.md` → 代表论文 `eo-gym`；再打开 `papers/eo-gym.md`。
4. 卡片给出：EO-Gym 把光学–SAR 切换写成一等动作；但这是交互环境证据，不是切换策略已解决。
5. 只有当需要动作空间/轨迹评分时，才打开 `pdfs/2026-arXiv-EO-Gym-Ma.pdf`。

## 写作 agent 的检索回复格式

每次给写作 agent 的检索结果，按以下字段返回（没有的写“无”或“未核”）：

```text
论文：<id> / bib key: <key>（已写入开题 ref.bib | 尚未写入开题 .bib）
PDF：pdfs/<file>（已打包） | 缺失：<missing-pdfs.md 原因 + 正式页链接>
可引用结论：
  1. <一句话结论>（来源：摘要 / 表 X / 第 X 节；已核正文 | 未核正文）
  2. ...
会址/状态：<正式会址 | 预印本 arXiv:xxxx | 已撤稿/不按录用引用>
与主张的关系：P1 模态–工具规划 | P2 轨迹级后训练 | 仅作感知底座或对照 | 背景文献
还缺什么：<需要打开全文核对的数字/协议/原文，或“无”>
```

规则：

- 每条“可引用结论”必须带来源位置与核对状态；没有来源就不写。
- 会址与预印本状态必须与卡片一致；卡片标“预印本”的，回复里不能升格为主会。
- 如果卡片本身标“未核正文”，回复必须保留这个标记。
- 如果用户只要“能不能引用”，先回答关系与边界，再给 1–2 条最强证据，不要倾倒整张卡。

## 引用纪律

以下规则同时约束目录与写作，**不要把它们写进论文正文去自我声明**：

- 不编造文献、页码、DOI、分数、会址或未核到的结论。
- 仍为预印本的工作保持预印本表述，不升格为主会录用。
- ThinkGeo 只作 arXiv:2505.23752 预印本，不以 ICLR / CVPR 主会论文引用。
- GeoAssistant 已撤稿，不作为录用论文引用。
- OpenEarthAgent（Shabbir，工具调用，arXiv:2602.17665）与 OpenEarth-Agent（Zhao，工具创造，arXiv:2603.22148）是两篇不同论文，不得混用。
- 不把不同评测协议下的分数排成对照表或 SOTA 榜。
- 感知底座（如 EarthDial、TEOChat、FUSAR-GPT）不得写成可以替代模态–工具规划的智能体方法。
- 会址只在仓库记录或正式页可核时写；arXiv 注释里的“Accepted at …”不自动等于已核正式论文集。
- 缺全文的 ExpertsRS、SPEXT 只能写元数据与正式页，不写方法细节、实验数字或“已精读”。

## Bib key 状态

- 39 条卡片沿用开题 `ref.bib` 中已有的 key，卡片写“已写入开题 `ref.bib`”。
- 22 条卡片尚未进入开题 `.bib`，卡片明确写“**尚未写入开题 `.bib`**”。需要引用时先补 bib 条目，再写入正文。
- 不要为同一篇论文另造第二个 key；OpenEarthAgent 与 OpenEarth-Agent 必须保留两个独立 key。

## 与 CLAIM 的关系

- [`CLAIM.md`](CLAIM.md) 是唯一主张来源；本目录不另起主张。
- P1 = 模态–工具规划：何时切换光学/SAR、切换后如何对齐/裁剪、如何调用检测/分割/损毁评估工具并校验参数与中间结果。
- P2 = 轨迹级后训练：用轨迹监督/蒸馏/RL 降低“步骤看似正确、最终答案却错误”。
- 感知底座与静态基准只能支撑“感知层不足/对照”，不能支撑 P1/P2 的机制性结论。
- 若一篇论文同时涉及 P1 与 P2，卡片只给一个主关系；跨用时要按卡片的能力边界重新限定。

## 结论标签

- `[摘要]`：摘要中直接可核的陈述。
- `[正文]`：正文（含表/节）中检索到的陈述；卡片“关键数字”会给出更具体位置。
- `[papers.json 摘要要点；未核正文]`：只能追溯到仓库转述，不能当作原文结论。
- `[目录判断]`：基于摘要与论文定位的编辑判断（例如“它不是工具 agent”），未逐节核正文；引用时保留限定语。

## 维护规则

- 官方目录以 `papers.json` 的 61 条为准；新增论文先进入 `papers.json`，再建卡片，不要直接从零散 PDF 建卡。
- 不改 `pdfs/` 已有文件名；不把付费墙正式版打包进来。
- 新增卡片必须复用本目录字段；结论只能来自摘要/正文/`SURVEY.md`，未核正文的必须标记。
- 发现未入库 PDF，只记录到 [`OUT_OF_CATALOG.md`](OUT_OF_CATALOG.md)，等待确认后再并入。
