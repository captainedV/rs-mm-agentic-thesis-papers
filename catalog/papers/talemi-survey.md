## 问题与方法

Agentic AI in Remote Sensing 综述：区分单 agent copilot 与多 agent 系统，梳理规划、RAG、记忆等架构基础，并 review 从像素精度转向轨迹感知正确性的 benchmark。

## 核心结论

- 综述给出 agentic RS 的统一 taxonomy：单 agent copilot vs 多 agent 系统。 [摘要]
- 它把规划机制、检索增强生成与记忆结构作为架构分析主轴。 [摘要]
- 它强调评测正在从 pixel-level accuracy 转向 trajectory-aware reasoning correctness。 [摘要]
- 它同时指出 grounding、安全与 orchestration 的局限，并给出路线图。 [摘要]
